# Rishi Hair Salon Website

Static website built for Cloudflare Pages.

## Files
- `index.html` — website content
- `styles.css` — responsive design
- `script.js` — mobile menu + current year
- `assets/logo.png` — supplied Rishi Hair Salon logo

## Before launch
Replace the five gallery placeholder tiles with real salon photos. The gallery is intentionally kept local so you can add photos without changing the layout.

## Cloudflare Pages
1. Create a GitHub repository and upload these files.
2. In Cloudflare, go to Workers & Pages → Create → Pages → Connect to Git.
3. Select the GitHub repository.
4. Framework preset: None.
5. Build command: leave blank.
6. Output directory: `/` (or the repository root).
7. Deploy.
8. Add your purchased domain under the project's Custom Domains.
9. If the domain is registered elsewhere, follow Cloudflare's DNS instructions to point it to the Pages project.
